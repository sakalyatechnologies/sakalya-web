# sakalya-web

Shared web building blocks for Sakalya Technologies: design tokens, the white-label theme engine and React components.

- Rules for humans and agents: [`AGENTS.md`](AGENTS.md)
- Packages and theming: [`docs/architecture.md`](docs/architecture.md)

```sh
pnpm install
pnpm dev      # gallery of every component and theme
pnpm check    # typecheck, lint, tests, build
```
